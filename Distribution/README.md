# YUIFramework 2.0 RC

Private Unity 2022.3 asynchronous uGUI framework. This exported package is generated
from one authoring source; do not edit the installed Runtime or create a parallel
copy under Assets.

Start with [the package quick start](Documentation~/PackageQuickstart.md), including
consumer dependency/registry configuration, `testables`, actual Package Manager
sample Import and the complete flow's EditorSimulate/Offline distinction.

device smoke, target-specific performance and license rights are independent gates.
