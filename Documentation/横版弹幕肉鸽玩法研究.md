# 横版射击 × 弹幕生存 × 肉鸽玩法研究

> 用途：为项目早期玩法讨论与可玩原型提供一份机制地图。本文是基于公开产品介绍和类型设计规律的桌面研究，不是销量、玩家规模或市场份额报告；参考作品用于拆解设计，不建议照搬其具体内容。
>
> 参考页面查看日期：2026-11-09。

## 1. 玩法定位建议

将目标体验概括为：

**玩家在横版战场中主动走位、跳跃与瞄准，面对持续涌来的敌人和可读的敌方弹幕；通过短波次奖励不断改造武器，逐步形成有辨识度的构筑，并在关键时刻释放大招扭转战局。**

它不是把三种类型的机制简单叠加，而要形成清晰分工：

- **横版动作**提供空间路线、跳跃/下落、地面与空中战斗，以及前后景层次。
- **弹幕射击**提供可观察、可预判、可躲避的危险，强调走位决策而非屏幕噪声。
- **生存肉鸽**提供每局随机选择、即时构筑、波次压力和重复游玩的变化。
- **射击构筑**让武器有不同操作节奏和战术用途，而不仅是换一张数值更高的枪。

建议首版核心支柱：

1. **移动即决策**：横向推进、上下平台、跳跃/闪避都能改变射击角度和避弹路线。
2. **枪械有手感差异**：散射、穿透、追踪、持续光束等武器要改变玩家的瞄准与站位。
3. **危险公平可读**：敌方弹幕有预警、方向、速度和安全窗口，受击原因容易理解。
4. **每局都形成一个构筑**：升级选择能改变攻击行为、资源循环或生存策略。

| [Risk of Rain Returns](https://store.steampowered.com/app/1337520/Risk_of_Rain_Returns/) | 横版动作肉鸽、角色技能、物品联动 | 横版空间、角色能力、成长压力与物品组合能够共存；物品联动能把普通攻击转化为连锁效果 | 时间压力和密集特效需要谨慎移植；必须保证屏幕拥挤后仍能看清敌人危险和平台边界 |

### 横向结论

- **节奏**可以参考《Brotato》的短波次与购物决策，避免全程只有一条不断增长的计时条。
- **操作**可以吸收《20 Minutes Till Dawn》和《Enter the Gungeon》的主动瞄准、开火与闪避，但控制方案要适配横版空间。
- **成长爽感**可以参考《Vampire Survivors》和《Risk of Rain Returns》的叠加与联动，同时为弹幕可读性设上限。
- **项目的差异点**应落在“横版平台空间如何改变弹幕攻防和构筑选择”，而不只是再做一款自动攻击生存游戏。

## 3. 战斗体验与核心循环

### 单次战斗循环（数秒）

```text
识别敌人/弹幕 → 选择射击方向与平台路线 → 输出或躲避 → 命中/受击反馈 → 重新定位
```

### 单波次循环（约 45–90 秒，原型建议）

```text
进入波次 → 敌人从多个高度/方向施压 → 击杀获得经验与资源
→ 精英或阶段事件制造峰值 → 清场/倒计时结束 → 选择升级或购买
```

### 单局循环（约 15–25 分钟，待测试）

```text
选角色/初始武器 → 连续波次与构筑选择 → 精英/首领检验构筑
→ 结算资源与解锁 → 再选角色、武器或路线开新局
```

建议一局由 **8–12 个战斗波次**构成，穿插精英波和 Boss；总时长应以实测为准。若想更偏短局，可将波次减少并缩短商店操作，不宜仅靠加快敌人速度压缩时长。

## 4. 武器与射击类型

武器差异最好同时体现在**弹道、射速/节奏、覆盖范围、有效距离、装填/热量、移动代价、升级方向**上。只改伤害和攻速，很快会收敛成同一种最佳解。

| 类型 | 战斗职责 | 操作/节奏特征 | 合适的升级方向 | 主要制衡 |
|---|---|---|---|---|
| 手枪 / 点射 | 入门、精准处理单体 | 单发或短点射，容易控制弹药 | 暴击、穿透、弱点伤害 | 对成群小怪覆盖有限 |
| 散弹枪 | 近距离清群、爆发 | 多枚弹丸扇形散开，贴近时命中更多 | 弹丸数、扇形角、近距离倍率、击退 | 射程短，贴近敌人有风险 |
| 冲锋枪 / 连射枪 | 稳定持续输出 | 高频、低单发伤害，适合持续跟踪目标 | 射速、弹匣、弹药回复、命中触发 | 换弹窗口、远距离精度或资源消耗 |
| 狙击 / 轨道炮 | 远程穿透、精英处理 | 慢速蓄力或低频高伤，一线贯穿 | 穿透数、蓄力缩短、暴击、标记 | 漏怪与近身压迫明显 |
| 追踪弹 / 制导弹 | 追击移动目标、降低瞄准压力 | 发射后转向目标；可设锁定、转弯和目标上限 | 追踪时间、分裂、弹头数、标记联动 | 单发伤害/速度较低，可能误追小怪 |
| 激光 / 光束 | 持续压制、扫线控场 | 按住或短时维持光束，命中连续结算 | 光束宽度、持续时间、折射/分叉、灼烧 | 需要持续暴露/瞄准，热量或能量限制 |
| 榴弹 / 火箭 | 范围爆发、清理密集敌群 | 抛射或直线飞行后爆炸 | 爆炸半径、子母弹、燃烧地面 | 弹速慢、近身误伤或自伤需慎用 |
| 弹跳 / 链式弹 | 利用敌群扩散伤害 | 命中后反弹或在目标间跳跃 | 跳跃次数、链电、击杀刷新 | 单体 Boss 伤害较弱 |
| 地雷 / 召唤物 | 区域控制、补足输出 | 预先布置、自动攻击或守点 | 数量、触发半径、存活时间、协同 | 机动推进时利用率较低 |
| 近战 / 盾击 | 近身破围、击退或防御 | 近距离扇形、格挡反击或短冲锋 | 范围、反击窗口、吸血、破甲 | 与远程弹幕空间冲突，风险高 |

### 武器数据建议

首版每把武器至少定义：

- 伤害、射速、弹速、射程、散布/宽度、穿透/目标数。
- 装填时长或能量/热量规则；若是持续武器，定义命中间隔与过热窗口。
- 瞄准模式：自由方向、8 向/360 度、自动选目标、锁定后发射。
- 空中/地面使用差异；是否影响移动、跳跃或闪避。
- 2–3 条可辨识的升级方向，以及 1–2 个能够与其他系统发生关系的关键词。

**重要原则：**“追踪”不是自动等于好用，“激光”也不应只是更粗的子弹。武器需要有明确的输出场景、空间代价和可见反馈。

## 5. 大招与组合技

大招应当是**构筑的高潮按钮**，而不是普通攻击的免费加倍版。建议先采用一个输入清楚的主动技能槽，再按构筑逐步扩展联动。

| 技能范式 | 效果示例 | 能创造的决策 |
|---|---|---|
| 清屏/弹幕消除 | 清除一定范围内的敌方子弹并造成伤害 | 留给弹幕最密集的危险窗口，或用于救急 |
| 定向爆发 | 对瞄准方向发射穿透炮/巨型激光 | 需要选对角度，奖励横向站位和瞄准 |
| 短时强化 | 数秒内提高射速、穿透或换弹速度 | 配合精英/Boss 暴露窗口 |
| 区域控制 | 放置护盾、减速场、持续电场 | 争夺平台或创造安全射击区 |
| 位移反击 | 瞬移/冲刺并在起点或终点反击 | 兼顾逃生与输出，但不应取代普通走位 |
| 召唤协同 | 召唤无人机/炮台/灵体协助攻击 | 强化持续输出构筑，提供阵地战变化 |

### 推荐的技能资源模型

- 通过造成伤害、击杀精英、成功闪避危险弹幕或拾取特定资源积累能量。
- 能量获取需有上限或递减，避免高攻速构筑无限循环大招。
- 大招应有明显前摇/提示、可辨认的范围和结束反馈；紧急防御类可缩短启动，但降低伤害。
- 让升级改变技能的**行为**（例如激光消弹、追踪弹命中后触发电弧），不要只堆冷却缩减。

### 组合技的构造方式

让组合技通过少量可理解的关键词发生，而非写死大量两两组合。

| 关键词 | 示例联动 |
|---|---|
| 点燃 | 火焰伤害叠加灼烧；灼烧目标死亡时留下短暂火区 |
| 感电 | 电击可在带标记敌人间跳跃；水/金属类敌人增加传导 |
| 标记 | 追踪弹优先追踪标记目标；狙击命中标记弱点时返还能量 |
| 穿透 | 轨道炮贯穿后降低后续伤害；穿透升级改变衰减而非无限叠加 |
| 击退 | 散弹/近战将敌人推入陷阱或火区；Boss 有抗击退阈值 |
| 暴击 | 暴击产生碎片弹、返还少量弹药或延长技能效果 |
| 冰冻/减速 | 减缓敌人或其弹幕；首领控制时间设上限 |

控制组合复杂度的规则：

1. 每个关键词要有容易读懂的图标、颜色和文字解释。
2. 单次触发链限制跳数/目标数，避免特效与伤害同时失控。
3. 增伤、控制、资源返还分别设上限，防止单一组合循环永动。
4. 每种组合至少有一个代价或适用局限，避免所有流派最终趋同。

## 6. 肉鸽成长结构

### 局内成长（当前这一局）

| 层级 | 形式 | 设计目的 |
|---|---|---|
| 战斗即时掉落 | 经验、临时能量、治疗、弹药 | 让玩家为拾取收益承担路线风险 |
| 波间奖励 | 三选一升级、商店购买、刷新/锁定 | 形成每几十秒一次的构筑决策 |
| 精英奖励 | 强化词条、稀有武器部件、技能改造 | 制造阶段目标和明显的力量跃迁 |
| Boss 奖励 | 大型专属升级、主动技能改造、关卡路线选择 | 作为流派确认点，推动中后期变化 |

升级池可按层次设计：

- **基础属性：**伤害、射速、装填、暴击、生命、护甲、移动速度、跳跃/闪避冷却。
- **武器改造：**散射加宽、激光折射、追踪分裂、弹丸穿透、爆炸附着状态。
- **战斗触发：**击杀爆炸、暴击回能、闪避后增伤、空中命中返还弹药。
- **生存机制：**护盾、受击无敌、治疗转护盾、危险区域减伤。
- **经济机制：**额外掉落、商店折扣、刷新次数、牺牲属性换资源。

### 局外成长（多局之间）

建议以**解锁选择**为主，永久数值成长为辅：

- 解锁新角色、初始武器、技能模块、物品和挑战/难度档。
- 通过挑战记录解锁玩法内容，而不是只靠重复刷同一资源。
- 若提供永久属性，应设置低幅度或分支取舍；避免新玩家因局外等级差而无法体验基础平衡。
- 失败也给少量稳定进度，但主要奖励应来自达成目标和探索新玩法。

### 角色差异

每个角色适合用“**一个优势 + 一个限制 + 一个玩法钩子**”表达。

示例：

- 散弹专家：近距离散弹伤害高；长距离衰减更快；击退敌人会积累冲锋能量。
- 制导工程师：追踪弹更强；自由瞄准伤害较低；击杀标记目标可部署短时炮台。
- 空中猎手：空中射击更精准；落地后短暂失去加成；连续空中命中可获得一次空中冲刺。
- 过热枪手：激光持续时间长；过热后有惩罚停火；主动冷却可释放短暂范围爆发。

## 7. 横版空间与敌方弹幕

横版不是只把摄像机转过来。它应为玩家提供可以读懂的战术空间：

- **纵向层次：**地面、可跳平台、上下层通道；敌人与子弹必须有清晰的高度/前后景归属。
- **站位风险：**边角可以提供输出机会，但要保留至少一条可逃路线，避免被迫贴边无解。
- **空中代价：**跳跃能越过地面扫射，但可能进入空中弹幕；设计需要让跳与闪避各有用途。
- **推进选择：**向右推进不必是唯一方向；回撤、下落或暂时固守都应是可行解。
- **射击与移动取舍：**移动射击可以降低精度、改变散布，或让部分重武器减速；不要让停下输出成为唯一最优行为。

敌方弹幕的基本公平规则：

1. 危险攻击先给提示（起手动作、地面标线、蓄力音效或弹道预览）。
2. 子弹速度、颜色、尺寸和伤害类别有稳定语义；高伤害攻击更容易识别。
3. 弹幕之间至少保留可通过的路径，且横版平台边缘不会封死全部逃生方向。
4. 同时出现的弹幕图案要区分“跳跃处理”“地面闪避”“横向穿越”等应对方式。
5. 屏幕特效密集时，玩家子弹不能覆盖敌方危险提示；提供降低闪光/特效的选项。
6. Boss 攻击组合先少后多，以攻击循环而非随机生成不可读弹幕制造挑战。

## 8. 敌人、波次与难度曲线

### 敌人职责组合

- **追击者：**迫使玩家移动与换平台。
- **远程炮手：**控制横向空间，发射可预测的点射/扇形弹幕。
- **冲锋者：**通过预警线制造横向压迫。
- **盾兵/装甲兵：**要求绕位、穿透或优先处理。
- **召唤/支援者：**延长战场压力，提供明确的集火目标。
- **精英：**基础敌人加一条可识别的强化规则，而不是单纯血量翻倍。
- **Boss：**阶段攻击、弱点窗口和场地机制检验当前构筑。

### 难度递进的可调维度

按顺序逐步增加，不要同时把全部旋钮调高：

1. 敌人数量与刷新节奏。
2. 敌人种类组合（近战压迫 + 远程区域控制）。
3. 弹幕方向、覆盖区域和攻击频率。
4. 精英词缀、波次事件、Boss 阶段。
5. 生存资源与安全窗口的稀缺程度。

难度应给构筑成形留出空间：前期让玩家理解核心操作，中期制造流派分化，后期检查构筑弱点，同时保留可通过操作纠错的机会。

## 9. 经济与奖励时机

- 经验负责**角色/战斗成长**；金币负责**商店决策**；技能能量负责**战斗内主动爆发**。三种资源职责要分开。
- 经验掉落应鼓励风险路线，但允许波间或阶段结算回收部分未拾取奖励，避免因平台落差造成过度挫败。
- 商店主要提供武器、升级、恢复、刷新/锁定等有限选择；不要让每波商店操作比战斗本身还耗时。
- 刷新与锁定能提升控制感，但要付出机会成本或逐步增加费用。
- 罕见强力奖励通过精英/Boss/挑战获得，普通升级负责稳定构筑方向。
- 失败奖励不要完全随机；提供稳定的解锁进度或挑战进展，强化“这局学到了什么”的感觉。

## 10. 首版可玩原型（MVP）建议

先验证“移动、瞄准、避弹、波间成长”是否构成有趣循环。暂不需要做海量角色、复杂局外树或大量特效。

### 建议内容范围

- 1 个横版场景，含地面与 2–3 个上下平台。
- 1 个角色，支持移动、跳跃、闪避、瞄准和开火。
- 3 把手感差异明显的武器：散弹、连射枪、追踪弹或激光（优先选三个）。
- 4 种普通敌人 + 1 种精英 + 1 个简单 Boss。
- 6–8 个短波次，波间三选一升级或小商店。
- 12–20 个局内升级，其中至少 4 个能改变攻击行为。
- 1 个大招，至少 2 种升级改造。
- 最小局外解锁：解锁一个武器/挑战即可；先验证内容循环，再拓展树状成长。

### 建议原型验证问题

- 玩家是否能一眼分清敌方弹幕和自己的投射物？
- 玩家会主动使用上下平台，而非全程留在一个位置吗？
- 三种武器是否带来不同的移动、瞄准和射击决策？
- 选择升级时，玩家是否能说出它会怎样改变当前玩法？
- 输掉一局后，玩家能否解释自己为何失败以及下局能尝试什么？
- 后期特效增加后，危险提示和平台边缘是否仍然看得清？

## 11. 平衡与可读性检查清单

- [ ] 每把武器都有目标场景、明显弱点和至少两个可选成长方向。
- [ ] 追踪、散射、激光、穿透、爆炸等攻击类型的命中反馈不同。
- [ ] 大招不会无限循环；充能来源与上限可被玩家理解。
- [ ] 连锁/状态组合有触发上限，Boss 控制效果有保护机制。
- [ ] 升级选择同时包含即时收益、构筑收益和风险/机会成本。
- [ ] 局外解锁增加玩法广度，不让永久数值成为通关的必要门槛。
- [ ] 每种敌方危险有预警、可躲避路径和明确的失败反馈。
- [ ] 不同颜色不会成为区分危险的唯一方式；考虑色觉差异。
- [ ] 受击、无敌、拾取、大招可用状态有清楚的视觉/音频反馈。
- [ ] 通过实测记录通关率、受击来源、武器选择率、升级选择率与每波时长，寻找过强/过弱的构筑。

## 12. 推荐先做的设计决定

开始扩充内容前，建议优先敲定以下四项，因为它们会影响操作、敌人和升级的整体设计：

1. **瞄准范围：**只准左右/8 向，还是可自由 360 度瞄准？横版平台战斗建议先验证 8 向或有限角度瞄准，降低操作负担。
2. **移动与开火：**所有武器是否允许移动射击？可考虑轻武器无惩罚、重武器减速，而不是一刀切。
3. **波次结构：**采用定时生存、清敌推进，还是两者混合？原型建议“计时波次 + 精英/目标事件”，确保波次结束节奏可控。
4. **闪避规则：**使用短冲刺、翻滚无敌帧，还是跳跃本身承担避弹？首版只保留一种可靠的紧急避险能力，再观察是否需要另一种。
